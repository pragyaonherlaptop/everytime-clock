# everytime-clock

hi, this project is a vintage pocket-watch style analog clock drawn entirely with SVG (no images).

it shows the real local time with smooth sweeping hands and a small seconds subdial at 6 o’clock.  
Every time a new hour begins, the whole watch elegantly spins 360° over 5 seconds.

## Features

- Fully code-drawn vintage pocket watch (SVG)
- Real-time hour, minute and seconds hands
- Small seconds dial at the bottom
- Automatic 360° spin animation every hour (5 seconds, ease-in-out)
- Manual spin trigger (button or keyboard)
- Demo mode that spins every minute (`?demo`)
- Customizable dial name
- Responsive SVG

## Live Demo

Open `index.html` in any modern browser, or host it on GitHub Pages.

**Demo mode**: add `?demo` to the URL to make the watch spin every minute instead of every hour.
